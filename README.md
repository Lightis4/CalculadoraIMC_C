# Calculadora de IMC em C

## Sobre o projeto

Programa desenvolvido em linguagem C para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

## Funcionalidades

- Entrada de peso e altura.
- Cálculo automático do IMC.
- Classificação do resultado.
- Validação de valores inválidos.

## Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Compilador GCC
- Visual Studio Code

## Como executar

Compile o programa:

```bash
gcc main.c -o imc
```

Execute no Windows:

```powershell
.\imc.exe
```

## Objetivo

Praticar variáveis, entrada e saída de dados, operações matemáticas e estruturas condicionais.

**Observação:** a classificação apresentada é uma referência geral para adultos e não substitui avaliação de saúde individual.
